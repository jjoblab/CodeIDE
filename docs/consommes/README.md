# Documents consommés

Documents de planification (briefs, plans, revues, spécifications)
dont **toutes les étapes ont été livrées et vérifiées**. Règle
propriétaire du 2026-10-20 — voir `AGENTS.md` §8 : dès qu'un document
de la racine de `docs/` n'a plus d'étape ouverte, il rejoint ce
dossier par `git mv` (jamais supprimé).

Ces documents ne se modifient plus ; ils restent consultables pour
la traçabilité des décisions qu'ils ont portées.
