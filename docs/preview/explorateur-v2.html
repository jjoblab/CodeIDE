Aperçu · Explorateur de fichiers v2

Proposition interactive pour CodeIDE — tiroir à fragments, arbre « treeview », popovers d'actions. À valider avant implémentation dans l'application Android (feature/editor + core/ui).

À essayer

  • Cliquer un fichier → sélectionné + ouvert dans l'onglet actif (point vert)
  • Appui long (ou clic droit) sur une ligne → popover d'actions ancré au doigt
  • Glisser la poignée ⋮ sur le bord droit du tiroir → élargir / rétrécir
  • Rail bas 📁 🔍 🌿 ⌗ → chaque fragment a son propre entête
  • Bascule Projet / Privé dans l'entête → arborescence du projet ou du privé
  • Copier / Couper puis appui long sur un dossier → Coller
  • Déplacer vers… → saisir le chemin de destination

Légende — point des fichiers

fichier simple sélectionné dans l'arbre ouvert dans l'onglet actif ouvert dans un onglet inactif
▸dossier — chevron de dépliage, traits fins •fichier — point d'état

Correspondance avec l'existant

  • Étend l'ADR 0027 (arborescence paresseuse, tri dossiers→fichiers)
  • Étend l'ADR 0030 (actions par nœud, « créer → éditer », URI migrée)
  • Rail bas actuel → fragments : Explorateur, Recherche, Git, Terminal
  • Entête commun supprimé → un entête par fragment

Maquette de validation — aucune de ces interactions n'est encore dans l'APK. Les mises à jour (nouveau, renommer, supprimer, copier, déplacer) s'appliquent au nœud concerné, sans recharger l'arbre entier.
