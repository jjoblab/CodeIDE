# feature/onboarding

travail SAF avec test d'écriture, apparence avec aperçu immédiat,
profil, terminé), pager non swipable, transitions MaterialSharedAxis.
L'état survit à la rotation et à la mort du processus.

Contenu fonctionnel, comportements clés et API publique : voir
`README.md` du module.
