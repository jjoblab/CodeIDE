# feature/editor

Espace de travail de l'éditeur, implémenté aux étapes 13-14 (v0.14.0, ADR 0026 — fondations sans logique ; v0.15.0, ADR 0027 — explorateur) : `EditorActivity` à trois zones (tiroir — permanent sur grand écran, avec **explorateur de fichiers paresseux** [cache ViewModel, tri dossiers/fichiers/alpha, icônes par extension, bandeau `ProjectAccessState`, barre basse Explorateur/Recherche/Git désactivées] ; zone centrale à états vides ; panneau inférieur replié Console · Problèmes · Journal), navigation `AppNavigator.openEditor` par-dessus la pile depuis l'accueil et le succès du wizard, `EditorViewModel` suivant le projet au registre via `SavedStateHandle`. Voir `README.md` du module.
